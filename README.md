# BioNova
BLOODLINK
A web-based platform connecting blood donors, hospitals, blood labs and blood camps to make blood availability faster and more accessible
Features:
🩸 Donor Registration
🏥 Hospital Registration
📋 Blood Requests
🔔 Blood Availability Alerts
🔐 Authentication
☁️ Supabase Database
📱 Responsive Web Interface
Technology:
HTML • CSS • JavaScript • Supabase
